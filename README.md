# cnn
遥感领域

## Transformer模型实现

本仓库包含一个完整的、可运行的Transformer模型实现，基于论文 "Attention is All You Need"。

### 快速开始

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行基本测试：
```bash
python transformer.py
```

3. 运行完整示例：
```bash
python example_transformer.py
```

### 文件说明

- `transformer.py` - 完整的Transformer模型实现
- `example_transformer.py` - 5个不同使用场景的示例代码
- `TRANSFORMER_README.md` - 详细的使用文档和API说明
- `requirements.txt` - 项目依赖

更多详细信息，请查看 [TRANSFORMER_README.md](TRANSFORMER_README.md)
